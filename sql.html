Exercício 1: Colunas e Limite LIMIT
O que pede: Traga a placa, o motorista, a origem e o destino das 10 primeiras viagens.
SELECT placa, motorista_nome, origem, destino FROM transporte LIMIT 10;
💡 Dica: LIMIT N serve para restringir a quantidade de linhas que o banco devolve.
Exercício 2: Duas Condições com AND AND
O que pede: Viagens que saíram de 'São Paulo' E foram para o 'Rio de Janeiro'.
SELECT placa, linha, data_viagem FROM transporte WHERE origem = 'São Paulo' AND destino = 'Rio de Janeiro';
💡 Dica: Texto sempre entre aspas simples 'São Paulo'. O AND exige as duas condições.
Exercício 3: Filtrar e Ordenar WHERE + ORDER BY
O que pede: Viagens com atraso maior que zero, da mais atrasada para a menos atrasada.
SELECT placa, linha, atraso_minutos FROM transporte WHERE atraso_minutos > 0 ORDER BY atraso_minutos DESC;
💡 Dica: DESC = maior para o menor (decrescente). ASC = menor para o maior.
Exercício 4: Lista de Opções IN (...)
O que pede: Viagens cujo destino seja 'Campinas', 'Santos' ou 'Joinville'.
SELECT placa, destino, distancia_km FROM transporte WHERE destino IN ('Campinas', 'Santos', 'Joinville');
💡 Dica: IN (...) substitui vários OR e deixa o código muito mais limpo.
Exercício 5: Cálculo de Consumo (KM/L) ROUND + DIVISÃO
O que pede: Calcule o consumo distancia_km / litros_combustivel com 2 casas decimais.
SELECT placa, distancia_km, litros_combustivel, ROUND(distancia_km / litros_combustivel, 2) AS km_litro FROM transporte LIMIT 10;
💡 Dica: O , 2) é do ROUND. O apelido AS km_litro dá nome à coluna calculada.
Teste Principal da SCS (Pior Consumo) 30 DIAS
O que pede: 5 veículos com pior média de consumo nos últimos 30 dias (viagens ≥ 50 km).
SELECT veiculo_id, placa, modelo, ROUND(SUM(distancia_km) / SUM(litros_combustivel), 2) AS km_por_litro FROM transporte WHERE data_viagem >= CURDATE() - INTERVAL 30 DAY AND distancia_km >= 50 GROUP BY veiculo_id, placa, modelo ORDER BY km_por_litro ASC LIMIT 5;
💡 Dica: Pior consumo = menor KM/L, por isso ordena com ASC (crescente).

⚠️ 4 Regras de Ouro para a Entrevista:

🚫
Nunca ponha vírgula antes do FROM: O último campo do SELECT não tem vírgula!
🔤
Texto = Aspas Simples: Use 'São Paulo', nunca aspas duplas.
📊
Regra do GROUP BY: Qualquer coluna no SELECT que não seja conta (soma/média) DEVE estar no GROUP BY.
🎯
WHERE vs HAVING: WHERE filtra linhas brutas (antes). HAVING filtra somas/médias (depois do agrupamento).
